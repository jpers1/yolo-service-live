YOLO Vision Demo

This local demo captures a camera frame, sends it to /v1/vision/detections, and draws returned detections on the preview.

Local/demo use only: browser-entered API keys are visible to the page runtime. Do not expose this demo with a shared real key on the public internet.

How it works

Click start, approve camera access, and keep this page on the same origin as the API. The loop sends one JPEG frame at a time and waits for the response before sending another frame, so no request backlog is built.
